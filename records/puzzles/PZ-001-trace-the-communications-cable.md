## How it works
A 5x5 map (columns A-E, rows 1-5) shows dashed communications cables and solid walking corridors. The fault strip says cables B1-C1 and C2-D2 are open. Cross those out, start at Docking A1 and follow the intact dashed cable to Bridge C3, reading each module's communications tag: A1 O, B1 R, B2 B, C2 I, C3 T.

## Player obtains
ORBIT, typed into HAROLD. HAROLD then releases the utility pouch code **4068** (a reward, not an extra puzzle).

## Solution
A1 -> B1 -> B2 -> C2 -> C3 = ORBIT.

## Hints
1. Use dashed cables.
2. Remove the two links named on the strip.
3. Follow A1, B1, B2, C2, C3: ORBIT.
