## How it works
Undo one captive hex fastener with the tool, open the CORE SERVICE panel, fit the keyed bridge cartridge on contacts X2-X3 (arrow toward RESTORE) and lift its verification flap. This is a tactile payoff, not an arithmetic puzzle.

## Player obtains
Core acknowledgement **C742** (beneath the cartridge flap). Memo EV-2702 and audit SG-17 become available. In Option B the app accepts the reported code and does not sense the cartridge; Option C could add a microswitch.

## Hints
1. Use the recovered tool only on CORE SERVICE.
2. Match X2-X3 and the arrow.
3. Fit the bridge, lift its flap and enter C742; keep both records for transmission.
